Apache Kafka:
----------------

- distribited event streaming platform
- message queue, sits between services and lets them commuinicate, without talking to each other

Kafka core concepts
----------------------

    - Producers:
        Service that sends message
    
    - Consumer:
        Service that recevies messages
    
    - Topic:
        Named channel for messages
    
    - Message:
        the actual data (usually JSON)
    
    - Broker:   
        Kafka server that stores messages 

HTTP vs Kafka
